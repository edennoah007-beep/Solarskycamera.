# Solar Sky Camera (Android)

Space zoom camera + live star map.

## Features
- Photo zoom up to 10,000x, video zoom up to 5,000x (log zoom slider, quick buttons, pinch)
- Uses the phone's real camera zoom first, then adds extra digital crop on top
- Highest photo resolution the phone offers; 4K UHD video when supported
- Zoom Map box (like Galaxy S24 Ultra) at 10x+ showing where you are pointing
- Target box that turns green when a planet/star is in frame
- "STEADY" shutter mode (waits until the phone stops shaking) + 3s / 10s timers
- AR labels for Sun, Moon, 7 planets, ~50 bright stars, galaxies & nebulae, horizon with N/E/S/W
- Sky Map: whole-sky dome with N / E / S / W that turns with your phone; tap a planet to be guided to it
- Exposure +/- (lower it for the Moon)
- Saves to Pictures/SolarSkyCamera and Movies/SolarSkyCamera

## Build the APK (no computer needed)
1. Create a free GitHub account, make a new repository, and upload all files from this folder (keep the folders).
2. Open the **Actions** tab -> "Build Solar Sky Camera APK" -> it runs automatically (or press "Run workflow").
3. When it finishes (~5 min), open the run and download **SolarSkyCamera-apk** (a zip with `app-debug.apk`).
4. On your phone, open the APK and allow "Install unknown apps".

## Or with Android Studio
Open this folder -> Build -> Build APK(s).
